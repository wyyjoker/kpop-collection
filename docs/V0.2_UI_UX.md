# V0.2 UI / UX Upgrade

V0.2 keeps the V0.1B data model and management APIs intact and adds a separate presentation/interaction layer.

## Experience changes

- Home collection insight cards for missing, Wishlist and preordered versions.
- Refined group cards and group hero styling.
- Album lists automatically regroup into release-year sections after every search/filter/sort render.
- Quick status chips stay synchronized with the existing status selector.
- Sticky desktop/mobile filter toolbar for long discographies.
- Version detail dialog becomes a desktop side drawer and a mobile bottom sheet.
- Mobile bottom navigation provides Home, Groups, Backup and Add actions.
- Mobile floating action button mirrors the existing primary add action.

## Architecture

V0.2 is intentionally additive:

- `public/app-v0.1b.js` remains the CRUD/business interaction layer.
- `public/app-v0.2.js` observes and enhances the rendered DOM.
- `public/v0.1b.css` remains the base component styling.
- `public/v0.2.css` overrides presentation and responsive behavior.
- `public/app.js` loads both layers in order.

This keeps V0.1B functionality easy to recover while allowing UI iteration without rewriting stable data-management code.
