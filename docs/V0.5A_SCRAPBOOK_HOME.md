# V0.5A — K-pop 收藏日记首页

V0.5A 只重构首页视觉，不修改 SQLite 数据结构，也不替换 V0.1B ~ V0.4 的管理、备份、收藏中心与 PWA 逻辑。

## 设计目标

将首页从深色 Dashboard 风格切换为粉彩 scrapbook / 手账拼贴风：奶油白纸张、粉色 / 薄荷绿 / 淡紫 / 天空蓝、Polaroid 相框、胶带感、手绘爱心 / 星星 / 兔子与便签。

## 页面结构

1. 顶部导航：主页、我的收藏、专辑图鉴、心愿清单、关于我、跨团体搜索。
2. Hero：`K-pop 收藏日记` + `Album Today, A Happier Me ☺`，自动使用已经上传的专辑和团体封面生成 Polaroid 拼贴。
3. 我喜欢的团：横向圆头像轨道，点击继续进入已有团体详情页。
4. 三栏主体：
   - 左：全部专辑 / 本命团 / 回归专辑 / 限定版 / 收藏清单 / 已拥有 / 想要收藏 / 待补 / 我的笔记。
   - 中：回归专辑卡片与限定版卡片。
   - 右：小小日常、最近收录、Wishlist、鼓励便签。
5. 桌面底部：粉色装饰播放器。V0.5A 不接真实音频。

## 第二轮视觉精修（Alpha 2）

- Hero 改成更接近目标参考图的三段式拼贴：左收藏房间 / 中央真实团体主图 / 右唱片机与专辑角。
- 新增 `room-shelf.svg` 与 `vinyl-corner.svg` 两套原创 scrapbook 场景插画，不依赖外部图片资源。
- 真实上传的团体封面作为 Hero 中央主视觉，真实专辑封面继续作为小型 Polaroid 贴纸叠加。
- Hero 增加真实 Groups / Albums / Owned / Completion 摘要，不引入消费和购买日期数据。
- 加强便利贴、胶带、撕纸边、虚线纸缝、手写短句等纸质手账细节。
- 团体头像缩小并提高横向密度，更接近参考图的“本命团”人物轨道。
- 专辑卡片缩小间距与阴影，让单位屏幕能展示更多专辑，同时保持状态标签清晰。
- 左侧分类、右侧日记卡、限定版区域统一为更轻的纸片视觉，减少传统 Web Card / Dashboard 感。
- 桌面播放器条进一步收窄，减少对内容区域的遮挡。
- 第二轮样式暂时独立在 `v0.5a-polish.css` / `app-v0.5a-polish.js`，便于快速评审；后续交给 Codex 时再合并整理，避免长期层叠。

## 数据映射

- Groups：`GET /api/groups`
- Albums / versions：对每个 group 读取 `GET /api/groups/:id`
- Wishlist：version.status = `wishlist`
- 收藏状态：根据 album 下的 version statuses 聚合为已拥有 / 部分拥有 / 想要收藏 / 已预购 / 待补。
- 最近收录：以当前数据库 album id 倒序显示最近录入的专辑，不依赖购买日期。
- 限定版：匹配 `edition_type` 或 `version_name` 中的 `limited / special / collector / digipack / pob / 限定 / 特典 / 收藏 / 珍藏`。

## 兼容策略

旧首页 DOM、`#groupGrid` 与原事件监听仍保留，只在首页视觉层中隐藏。V0.5A 团体入口会触发已有 `#groupGrid` 卡片，因此仍复用原来的 `openGroup()`、CRUD 与详情页逻辑。

进入团体详情页后 `body.v5a-home-active` 会被移除，V0.4 界面继续正常使用；回到首页时再恢复 scrapbook 首页。

## 响应式

- Desktop：左侧分类 + 中央专辑区 + 右侧日记栏三栏布局；Hero 显示完整三段式场景。
- Tablet：Hero 隐藏左右场景，保留真实团体主图；分类变为横向 chips，右栏改为三列卡片。
- Mobile：单栏，团体横向滚动，专辑 / 限定版双列，右栏顺序下移；Hero 只保留中央主图与精简装饰；装饰播放器隐藏，避免与 V0.2/PWA 底部导航冲突。
