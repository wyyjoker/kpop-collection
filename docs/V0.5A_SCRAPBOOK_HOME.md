# V0.5A — K-pop 收藏日记首页

V0.5A 只重构首页视觉，不修改 SQLite 数据结构，也不替换 V0.1B ~ V0.4 的管理、备份、收藏中心与 PWA 逻辑。

## 设计目标

将首页从深色 Dashboard 风格切换为粉彩 scrapbook / 手账拼贴风：奶油白纸张、粉色 / 薄荷绿 / 淡紫 / 天空蓝、Polaroid 相框、胶带感、手绘爱心 / 星星 / 兔子与便签。

## 页面结构

1. 顶部导航：主页、我的收藏、专辑图鉴、心愿清单、关于我、跨团体搜索。
2. Hero：`K-pop 收藏日记` + `Album Today, A Happier Me ☺`，自动使用已经上传的专辑和团体封面生成 Polaroid 拼贴。
3. 我喜欢的团：横向圆头像轨道，点击继续进入已有团体详情页。
4. 三栏主体：
   - 左：全部专辑 / 本命团 / 回归专辑 / 限定版 / 收藏清单 / 已拥有 / 想要收藏 / 待补 / 我的笔记。
   - 中：回归专辑卡片与限定版卡片。
   - 右：小小日常、最近收录、Wishlist、鼓励便签。
5. 桌面底部：粉色装饰播放器。V0.5A 不接真实音频。

## 第二轮视觉精修（Alpha 2）

- Hero 改成三段式拼贴：左收藏房间 / 中央真实团体主图 / 右唱片机与专辑角。
- 新增 `room-shelf.svg` 与 `vinyl-corner.svg` 两套原创 scrapbook 场景插画。
- Hero 增加真实 Groups / Albums / Owned / Completion 摘要。
- 团体头像、专辑卡、分类栏和右侧日记栏整体减轻 Dashboard 感。

## Hero 第三轮拼贴墙（Alpha 3）

- Hero 不再以三张大卡片为最终视觉，而是由新的 layered collage wall 接管。
- 自动读取最多 6 个团体的详情，并优先选取团体封面、最近发行专辑封面组成照片墙。
- `room-shelf.svg` / `vinyl-corner.svg` 仍作为生活场景底图，但和真实收藏封面混排，不再独立占据三等分栏位。
- 照片墙最多显示 9 张不同大小、角度和层级的图片。
- 标题位于中间层；背景照片位于标题后方；底部 3 张前景 Polaroid 的 z-index 高于标题，使图片边缘自然压住标题下沿。
- 新增原创 `doodle-flower.svg` 与 `doodle-bow.svg`，并增加多段 washi tape、星星、爱心与手写短句。
- Hero 底部加入 `GOOD MUSIC · BETTER DAYS · KEEP COLLECTING` 纸条，强化手账封面而非 Web Banner 的感觉。
- 桌面端保留完整照片墙；平板减少外围场景；手机端保留中央大图 + 左右照片 + 三张前景小卡，避免视觉过载。
- 第三轮独立在 `app-v0.5a-hero.js` / `v0.5a-hero.css`，用于视觉确认。V0.5A 设计稳定后再由 Codex 合并整理多个增强层。

## 数据映射

- Groups：`GET /api/groups`
- Albums / versions：对 group 读取 `GET /api/groups/:id`
- Hero 第三轮只读取前 6 个团体详情用于生成封面拼贴，避免首页为了视觉层请求过多数据。
- Wishlist：version.status = `wishlist`
- 收藏状态：根据 album 下的 version statuses 聚合为已拥有 / 部分拥有 / 想要收藏 / 已预购 / 待补。
- 最近收录：以当前数据库 album id 倒序显示最近录入的专辑，不依赖购买日期。
- 限定版：匹配 `edition_type` 或 `version_name` 中的 `limited / special / collector / digipack / pob / 限定 / 特典 / 收藏 / 珍藏`。

## 兼容策略

旧首页 DOM、`#groupGrid` 与原事件监听仍保留，只在首页视觉层中隐藏。V0.5A 团体入口会触发已有 `#groupGrid` 卡片，因此仍复用原来的 `openGroup()`、CRUD 与详情页逻辑。

第二轮三段式 Hero DOM 继续作为回退层保留；第三轮启用时由 CSS 隐藏旧三段式舞台。进入团体详情页后 Hero 增强层退出，不影响 V0.4 详情页。

## 响应式

- Desktop：完整多层拼贴墙 + 标题前后遮挡 + 三栏主体。
- Tablet：隐藏最外围两张场景大图，保留中央主图和前景 Polaroid。
- Mobile：精简到中央主图、左右照片与三张小前景卡；隐藏大部分胶带和装饰，避免与 PWA 底部导航冲突。
