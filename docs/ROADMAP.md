# Roadmap

## V0.1 — Album Collection Foundation

- Groups
- Albums
- Album versions
- Collection status: owned / missing / wishlist / preordered
- Cover image upload
- Search, year filter, status filter and sorting
- Responsive mobile-first UI

## V0.1B — Collection Management

- Edit and delete groups/albums/versions
- Collection detail editor
- Better collection status controls
- JSON import/export
- SQLite backup and restore

## V0.2 — UI / UX & Group Collection Experience

- Home collection insight cards
- Refined group cards and immersive group hero
- Albums automatically grouped by release year
- Quick status filter chips
- Sticky filter toolbar
- Desktop version detail side drawer
- Mobile version detail bottom sheet
- Mobile bottom navigation and floating add button
- Preserve V0.1B CRUD and backup behavior through a separate enhancement layer

## V0.3 — Wishlist & Collection Center

- Dedicated Wishlist dashboard
- Missing-version overview
- One-click mark as owned from Wishlist / missing lists
- Group completion rankings
- Release-year completion overview
- Collection status distribution
- Group and keyword filtering
- No spending statistics
- No purchase-date requirement

## V0.4 — PWA & Mobile App Experience

- Web App Manifest and standalone display mode
- Android / desktop install prompt
- iOS Add to Home Screen guidance
- 192 / 512 / maskable / Apple Touch app icons
- Service Worker offline application shell
- Keep API data and uploaded collection covers network-only
- Offline status banner
- Safe-area support for notch / Dynamic Island / Home Indicator
- PWA shortcuts for Wishlist and missing versions
- CI validation for manifest, icons, Service Worker and PWA endpoints

## Later

- Photocards
- Members
- Store benefits / POB
- Automatic album metadata assistance
