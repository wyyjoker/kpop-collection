# Roadmap

## V0.1 — Album Collection Foundation

- Groups
- Albums
- Album versions
- Collection status: owned / missing / wishlist / preordered
- Cover image upload
- Search, year filter, status filter and sorting
- Responsive mobile-first UI

## V0.1B — Collection Management

- Edit and delete groups/albums/versions
- Detailed purchase information editor
- Better collection status controls
- JSON import/export
- SQLite backup and restore

## V0.2 — UI / UX & Group Collection Experience

- Home collection insight cards
- Refined group cards and immersive group hero
- Albums automatically grouped by release year
- Quick status filter chips
- Sticky filter toolbar
- Desktop version detail side drawer
- Mobile version detail bottom sheet
- Mobile bottom navigation and floating add button
- Preserve V0.1B CRUD and backup behavior through a separate enhancement layer

## V0.3 — Wishlist & Statistics

- Dedicated Wishlist dashboard
- Spending statistics
- Group completion rankings
- Missing-version overview
- Purchase timeline and recent acquisitions

## V0.4 — PWA

- Installable mobile experience
- Offline shell
- Home-screen icon and app manifest

## Later

- Photocards
- Members
- Store benefits / POB
- Automatic album metadata assistance
